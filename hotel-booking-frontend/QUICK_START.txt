┌───────────────────────────────────────────────────────────────────────────┐
│  TESTING DIFFERENT ROLES                                                  │
└───────────────────────────────────────────────────────────────────────────┘

  To test different dashboard roles:
  
  1. Open: src/pages/Login.jsx
  2. Find line 16: role: 'user'
  3. Change to: 'admin', 'manager', 'receptionist', 'waiter', 'cook', or 'user'
  4. Login with any email/password
  5. You'll be redirected to the appropriate dashboard

  ROLE MAPPINGS:
  ├─ admin         → /dashboard/admin (Full statistics)
  ├─ manager       → /dashboard/employee (Time greeting)
  ├─ receptionist  → /dashboard/employee (Time greeting)
  ├─ waiter        → /dashboard/employee (Time greeting)
  ├─ cook          → /dashboard/employee (Time greeting)
  └─ user          → /dashboard/user (Profile & bookings)
